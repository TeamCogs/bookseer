# Contributing

Bookseerr currently has one maintainer and code contributor: [Scott / TeamCogs](https://github.com/TeamCogs).

Bug reports, reproducible examples, and feature suggestions are welcome through GitHub issues. Please do not include credentials, API keys, access tokens, database files, or private library exports.

External code contributions are not being accepted at this stage. Unsolicited pull requests may be closed. Public forks are permitted under the MIT license; they do not grant write access to this repository.

Repository commits are authored by the owner. No collaborators, automated commit authors, or co-author trailers should be added without the owner's explicit instruction.
